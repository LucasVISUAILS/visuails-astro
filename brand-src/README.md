# brand-src

Source material that is deliberately **not** published. Astro only serves
`public/`, so nothing in this folder ships.

- `logo-mark-blue-2025.webp` — the original cyan-to-periwinkle V monogram, kept
  because it is the raster the current vector monogram was traced from
  (`<symbol id="markglyph">` in `src/layouts/Layout.astro`, IoU 99.72% against
  this file). It was retired in the monochrome/chrome pass: it was the last
  saturated colour on the site, and at 1.39:1 against the mobile drawer's paper
  ground it was a logo you could not see.
